SECTION 1: CORE CONCEPTS & WHAT YOU ARE BUILDING (READ THIS FIRST!)
====================================================================================================

1. WHAT IS A MONOLITH? (Your Current Setup)
   Right now, all your backend Java code (Auth, Users, Submissions, 64 Audit Tables, File Uploads,
   and Database Backups) runs inside ONE single Spring Boot application on port 8080.
   If one part crashes, the whole app stops working.

2. WHAT IS A MICROSERVICES ARCHITECTURE? (What We Are Building)
   We split the big monolith into small, focused, independent Spring Boot applications called
   "Microservices". Each microservice has its own folder, its own port, and its own database.

3. WHAT IS AN API GATEWAY?
   The API Gateway acts as the single "Front Door" for your backend on port 8080.
   Your React frontend will STILL communicate ONLY with port 8080! You do NOT need to change
   frontend URLs. The Gateway checks the URL path and routes the request internally:
     - `/api/auth/**` & `/api/users/**`   --> Sent to Auth Service (Port 8081)
     - `/api/academic/**`                 --> Sent to Form Data Service (Port 8082)
     - `/api/submissions/**`              --> Sent to Submission Service (Port 8083)
     - `/api/attachments/**` & `/uploads` --> Sent to Storage Service (Port 8084)
     - `/api/backup/**`                   --> Sent to Admin Service (Port 8085)

4. WHAT IS THE STRANGLER FIG PATTERN?
   We will move services one by one! First, we put the API Gateway in front of the existing monolith.
   Then we extract Auth, then Storage, then Form Data, then Submissions. At every step, the application
   remains 100% working!

SECTION 4: PHASE 1 — SETTING UP MULTI-MODULE MAVEN PROJECT STRUCTURE
====================================================================================================

In this phase, we transform your project directory into a Maven Multi-Module workspace.

STEP 1.1: Create Databases in PostgreSQL
Open your PostgreSQL terminal (psql or pgAdmin) and run these SQL statements:

  CREATE DATABASE appraisal_auth_db;
  CREATE DATABASE appraisal_forms_db;
  CREATE DATABASE appraisal_submission_db;

STEP 1.2: Backup Existing Code
Before making changes, make a backup copy of your project folder:
Copy `director-appraisal` to `director-appraisal-monolith-backup`.

STEP 1.3: Update Root `pom.xml`
Open `director-appraisal/pom.xml` and change `<packaging>` to `pom`, adding `<modules>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.director-appraisal</groupId>
    <artifactId>director-appraisal-parent</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <packaging>pom</packaging>
    <name>director-appraisal-parent</name>

    <modules>
        <module>api-gateway</module>
        <module>auth-user-service</module>
        <module>form-data-service</module>
        <module>submission-service</module>
        <module>storage-service</module>
        <module>admin-service</module>
    </modules>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.3.4</version>
    </parent>

    <properties>
        <java.version>17</java.version>
        <spring-cloud.version>2023.0.3</spring-cloud.version>
        <jjwt.version>0.12.5</jjwt.version>
    </properties>

    <dependencyManagement>
        <dependencies>
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-dependencies</artifactId>
                <version>${spring-cloud.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
    </dependencyManagement>
</project>
```

SECTION 5: PHASE 2 — BUILDING THE API GATEWAY (`api-gateway` on Port 8080)
====================================================================================================

The API Gateway is the central router. It receives all HTTP requests from the React frontend on
port 8080 and forwards them to the appropriate microservice.

STEP 2.1: Create Directory Structure for `api-gateway`
In PowerShell or Terminal at `director-appraisal/`:
  mkdir api-gateway
  mkdir api-gateway/src/main/java/com/director_appraisal/gateway
  mkdir api-gateway/src/main/resources

STEP 2.2: Create `api-gateway/pom.xml`
Create file `api-gateway/pom.xml` with content:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>com.director-appraisal</groupId>
        <artifactId>director-appraisal-parent</artifactId>
        <version>0.0.1-SNAPSHOT</version>
    </parent>

    <artifactId>api-gateway</artifactId>

    <dependencies>
        <dependency>
            <groupId>org.springframework.cloud</groupId>
            <artifactId>spring-cloud-starter-gateway</artifactId>
        </dependency>
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-api</artifactId>
            <version>${jjwt.version}</version>
        </dependency>
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-impl</artifactId>
            <version>${jjwt.version}</version>
            <scope>runtime</scope>
        </dependency>
        <dependency>
            <groupId>io.jsonwebtoken</groupId>
            <artifactId>jjwt-jackson</artifactId>
            <version>${jjwt.version}</version>
            <scope>runtime</scope>
        </dependency>
    </dependencies>
</project>
```

STEP 2.3: Create `api-gateway/src/main/resources/application.yaml`
Create file with routing configuration:

```yaml
server:
  port: 8080

spring:
  application:
    name: api-gateway
  cloud:
    gateway:
      globalcors:
        corsConfigurations:
          '[/**]':
            allowedOriginPatterns: "*"
            allowedMethods:
              - GET
              - POST
              - PUT
              - DELETE
              - OPTIONS
              - PATCH
            allowedHeaders: "*"
            exposedHeaders:
              - Authorization
              - Content-Type
            allowCredentials: true
      routes:
        - id: auth-service
          uri: ${AUTH_SERVICE_URL:http://localhost:8081}
          predicates:
            - Path=/api/auth/**, /api/users/**

        - id: form-data-service
          uri: ${FORMS_SERVICE_URL:http://localhost:8082}
          predicates:
            - Path=/api/academic/**, /api/administrative/**

        - id: submission-service
          uri: ${SUBMISSION_SERVICE_URL:http://localhost:8083}
          predicates:
            - Path=/api/submissions/**, /api/audit-cycles/**

        - id: storage-service
          uri: ${STORAGE_SERVICE_URL:http://localhost:8084}
          predicates:
            - Path=/api/attachments/**, /uploads/**

        - id: admin-service
          uri: ${ADMIN_SERVICE_URL:http://localhost:8085}
          predicates:
            - Path=/api/backup/**
```

STEP 2.4: Create Main Class `ApiGatewayApplication.java`
Create file `api-gateway/src/main/java/com/director_appraisal/gateway/ApiGatewayApplication.java`:

```java
package com.director_appraisal.gateway;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class ApiGatewayApplication {
    public static void main(String[] args) {
        SpringApplication.run(ApiGatewayApplication.class, args);
    }
}
```

SECTION 6: PHASE 3 — EXTRACTING `auth-user-service` (PORT 8081)
====================================================================================================

This microservice handles user authentication, JWT access tokens, 7-day refresh tokens, MFA OTP,

STEP 3.1: Create Directory Structure for `auth-user-service`
  mkdir auth-user-service
  mkdir auth-user-service/src/main/java/com/director_appraisal/auth
  mkdir auth-user-service/src/main/resources/db/migration

STEP 3.2: Copy Source Code from Monolith into `auth-user-service`
Copy these packages from `src/main/java/com/director_appraisal/director_appraisal/`:
  - `controller/AuthController.java` & `controller/UserController.java`
  - `model/User.java`, `UserAdministrativePost.java`, `RefreshToken.java`, `MfaLoginSession.java`, `PasswordResetToken.java`
  - `repository/UserRepository.java`, `UserAdministrativePostRepository.java`, `RefreshTokenRepository.java`, `MfaLoginSessionRepository.java`, `PasswordResetTokenRepository.java`
  - `service/UserService.java`, `JwtService.java`, `RefreshTokenService.java`, `MfaService.java`, `RateLimiterService.java`, `EmailService.java`
  - `config/SecurityConfig.java`, `JwtRequestFilter.java`

STEP 3.3: Copy Flyway Migrations for Auth
Copy migrations V1, V2, V15, V17, V19, V21 into `auth-user-service/src/main/resources/db/migration/`:
  - `V1__init_auth_schema.sql` (Only `users` & `user_administrative_posts` tables)
  - `V2__create_mfa_sessions.sql` (`mfa_login_sessions` & `password_reset_tokens`)
  - `V3__add_avatar_url.sql` (`alter table users add avatar_url`)
  - `V4__create_refresh_tokens_table.sql` (`refresh_tokens`)

STEP 3.4: Configure `application.yaml` for `auth-user-service`
Create `auth-user-service/src/main/resources/application.yaml`:

```yaml
server:
  port: 8081

spring:
  application:
    name: auth-user-service
  datasource:
    url: ${DATABASE_URL:jdbc:postgresql://localhost:5432/appraisal_auth_db}
    username: ${DB_USERNAME:postgres}
    password: ${DB_PASSWORD:postgres}
    driver-class-name: org.postgresql.Driver
  jpa:
    hibernate:
      ddl-auto: validate
    database-platform: org.hibernate.dialect.PostgreSQLDialect
  flyway:
    enabled: true
    baseline-on-migrate: true
    locations: classpath:db/migration

app:
  jwt:
    secret: ${JWT_SECRET:SecretKeyForJWTAppraisalMustBeAtLeast256BitsLongForHMACSHA256}
    expiration-ms: 86400000        # 24 hours
    refresh-expiration-ms: 604800000 # 7 days
```

STEP 6.4: Create OpenFeign Client `AuthClient.java`
Because `submission-service` is in a separate application from `auth-user-service`, it cannot directly call `UserRepository` via Java injection. Instead, it makes an HTTP call via OpenFeign:

Create `submission-service/src/main/java/com/director_appraisal/submission/client/AuthClient.java`:

```java
package com.director_appraisal.submission.client;

import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import java.util.Map;

@FeignClient(name = "auth-user-service", url = "${AUTH_SERVICE_URL:http://localhost:8081}")
public interface AuthClient {

    @GetMapping("/api/users/by-email/{email}")
    Map<String, Object> getUserByEmail(@PathVariable("email") String email);

    @GetMapping("/api/users/{id}")
    Map<String, Object> getUserById(@PathVariable("id") Long id);
}
```

SECTION 12: FREQUENTLY ASKED QUESTIONS & TROUBLESHOOTING
====================================================================================================

Q1: Do I need to change anything in the React Frontend?
A1: NO! The React frontend still sends all HTTP requests to `http://localhost:8080`.
    The API Gateway transparently routes requests to the 5 backend microservices!

Q2: What happens if `auth-user-service` is down?
A2: Only login and user management endpoints will fail. Users who are already logged in can
    continue viewing submissions because JWT validation is stateless at the Gateway!

Q3: How do microservices talk to each other?
A3: Using Spring Cloud OpenFeign! `submission-service` calls `@FeignClient` interfaces to fetch
    user details from `auth-user-service` over HTTP REST.

Q4: What if I get a `Connection Refused` error?
A4: Ensure PostgreSQL is running on port 5432 and that all 3 databases (`appraisal_auth_db`,
    `appraisal_forms_db`, `appraisal_submission_db`) exist before launching the services.
